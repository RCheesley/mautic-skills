# Console command inventory (Mautic 7.x)

Every console command registered by `app/bundles/` and `plugins/` in 7.2.1, plus the Symfony commands that Mautic
operation depends on. The list was built from section 6 of each code analysis and cross-checked against a grep of
`#[AsCommand]` in the 7.x tree [code: app/bundles/*/Command/*.php, plugins/*/Command/*.php @7.x].

Column legend:
- **Lock**: `Moderated` = extends `ModeratedCommand` and calls `checkRunStatus()`; a second concurrent run with the
  same lock key prints `Script in progress. Can force execution by using --bypass-locking.` and exits **0**.
  `Moderated (ignored)` = extends `ModeratedCommand` but never calls `checkRunStatus()`, so the lock options are
  accepted and do nothing. `None` = plain Symfony `Command`; concurrent runs are not prevented.
- **Frequency**: only frequencies that a source states. "No source" means no input gives a frequency; do not invent one.
- Exit codes: `0` = `Command::SUCCESS`, `1` = `Command::FAILURE`, `2` = `Command::INVALID`, `130`/signal = `ExitCode::TERMINATED`.

Moderated-command options (all moderated commands): `--bypass-locking`, `--timeout|-t`, `--lock_mode|-x`
(`pid` default, `flock`, `redis`; `file_lock` maps to `flock`), `--force|-f` (deprecated alias of `--bypass-locking`)
[code: app/bundles/CoreBundle/Command/ModeratedCommand.php:56-74 @7.x].
