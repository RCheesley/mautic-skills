# Troubleshooting docs and KB articles (digest)

What the official troubleshooting pages and the Knowledge Base say, with URLs, and whether each source is outdated
for Mautic 7.x. "Outdated" verdicts come from the KB digest's own assessment, or from a code citation where the skill
set has checked the claim. When a source and the code disagree, the code wins.

## 5. Known doc-versus-code disagreements that affect troubleshooting

- Docs say `config/local.php` vs `app/config/local.php` in different places; 7.x reads `config/local.php`. [code: app/bundles/CoreBundle/Loader/ParameterLoader.php:195-216 @7.x]
- Docs and KB say only "Administrators" are ignored when testing tracking; code ignores every logged-in User. [code: app/bundles/PointBundle/Model/PointModel.php:176-178 @7.x] [docs: https://docs.mautic.org/en/7.2/points/points_troubleshooting.html#page-visits-not-recognized]
- Docs say only Email uses the queue; the `hit` transport also queues email opens and page hits. [docs: https://docs.mautic.org/en/7.2/configuration/settings.html#purpose-of-the-queuing] [code: app/config/config.php:111-125 @7.x]
- Docs and the CLI page list commands absent from 7.x (`mautic:queue:process`, `mautic:email:send`, `mautic:citrix:sync`, `mautic:integration:pipedrive:*`). [docs: https://docs.mautic.org/en/7.2/configuration/command_line_interface.html#mautic-commands]
- Docs say the Segment-email cron sends later Contacts unless an unpublish date is set; code does so only with Continue sending on. [code: app/bundles/EmailBundle/Entity/EmailRepository.php:285-288 @7.x] [docs: https://docs.mautic.org/en/7.2/configuration/cron_jobs.html#send-scheduled-broadcasts-segment-emails-cron-job]
- Docs say CORS "Restrict Domains" defaults to No; code defaults to `true`. [code: app/bundles/CoreBundle/Config/config.php:702 @7.x] [docs: https://docs.mautic.org/en/7.2/configuration/settings.html#cors-settings]
- `mautic:install` docs list `--mailer_*` options that 7.2.1 does not define. [code: app/bundles/InstallBundle/Command/InstallCommand.php:58-147 @7.x]
