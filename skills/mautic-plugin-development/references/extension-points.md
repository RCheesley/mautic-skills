# Extension-point catalogue (7.x hook → 8.x equivalent)

How to read this table:
- "7.x hook" is what a plugin subscribes to, tags or declares on 7.2.1. Constants were verified in the 7.x tree with `grep` (files cited per row).
- "8.x" uses three markers from the 8.x delta analysis [code: 8x-changes §3.2-3.3 @8.x]:
  - **removed** — the constant (or whole `*Events` class) no longer exists; referencing it is a fatal `Error`; key on the class.
  - **kept, not dispatched** — the constant still exists but core dispatches the event by class; a subscriber keyed on the constant loads and never fires.
  - **string** — still dispatched under a string name on 8.x (plugin-owned names, CRUD groups, campaign registration names).
- Write both-version subscribers by keying on the class and adding the constant when `defined()` [code: 8x-changes §7 @8.x].
- "Deep dive" names the skill that owns the feature's behaviour.

## 15. Things that are not extension points
- Overriding core classes or templates from a plugin is discouraged; contribute the hook instead [devdocs: https://devdocs.mautic.org/en/7.2/plugins/getting_started.html].
- `themes/system` overrides core templates; that is a Theme concern [devdocs: https://devdocs.mautic.org/en/7.2/plugins/mautic_vs_symfony.html#custom-directory-structure].
- There is no uninstall hook [devdocs: https://devdocs.mautic.org/en/7.2/plugins/installation.html].
- `PluginEvents::ON_FORM_SUBMIT_ACTION_TRIGGERED` is declared in 7.x but never dispatched [code: integrations-plugins-marketplace §4.1 @7.x].
