## 1. Theme discovery, validity and selection

B1. A directory under `themes/` is a theme only if it contains `config.json`; others are skipped [code: TH:716-751 @7.x].
B2. Themes live in `<webroot>/themes/<dir>`; the Twig namespace `@themes` maps to `%mautic.application_dir%/themes` [code: app/config/paths.php:5 @7.x] [code: app/config/config_prod.php:66-70 @7.x]. For docroot installs `PathsHelper::getSystemPath('themes', true)` resolves against `localRoot` [code: app/bundles/CoreBundle/Helper/PathsHelper.php:247-256 @7.x].
B3. `config.json` keys: `name` (required), `author`, `authorUrl`, `features` (`email`/`page`/`form`), `builder` (array of builder names), `tags` (7.2+) [code: TH:716-751 @7.x] [devdocs: https://devdocs.mautic.org/en/7.2/themes/getting_started.html#configuration-file].
B4. A theme object for a directory without `config.json`, or with no `name`, throws `BadConfigurationException`; a missing directory throws `FileNotFoundException` [code: app/bundles/CoreBundle/Twig/Helper/ThemeHelper.php:36-50 @7.x]. Test: `ThemeHelperTest::testExceptionThrownWithMissingConfig`.
B5. `builder` defaults to `['legacy']` when absent; a present non-array value throws `BadConfigurationException` [code: TH:734-736,778-783 @7.x].
B6. `getInstalledThemes($feature)` returns only themes whose `features` contains the feature and whose `builder` contains the active builder name for that feature, or `legacy` when no published builder supports it [code: TH:756-786 @7.x]. Tests: `ThemeHelperTest::testLegacyThemesAreReturnedForFeatureIfNoCustomBuilderIsEnabled`, `testCustomThemesAreReturnedForFeatureIfCustomBuilderIsEnabled`.
B7. The active builder for a feature is the first published `mautic.builder_integration` service whose `isSupported($feature)` is true; none → `IntegrationNotFoundException`, treated as `legacy` [code: app/bundles/IntegrationsBundle/Helper/BuilderIntegrationsHelper.php:37-49 @7.x]. GrapesJS supports `email` and `page` only [code: GJ/Integration/Support/BuilderSupport.php:15-19 @7.x]. GrapesJS is installed published [code: GJ/InstallFixtures/ORM/GrapesJsData.php:27-57 @7.x].
B8. Consequence: with GrapesJS published, legacy-only themes (aurora, cards, fresh-*, goldstar, neopolitan, oxygen, skyline, sparse, sunday, vibrant) are not offered for Email or Landing Page; for Form, themes with `legacy` or no `builder` key are offered [code: TH:756-786 @7.x] [code: GJ/Integration/Support/BuilderSupport.php:15-19 @7.x].
B9. Results are cached per request per `(feature, includeDirs)`; the Theme Manager list always reloads [code: TH:269-282 @7.x] [code: app/bundles/CoreBundle/Controller/ThemeController.php:92 @7.x]. Test: `testCachedThemesReturnAsExpected`.
B10. The extended listing returns `name`, `key`, `config` (with defaulted `builder`), `visibility.hidden` for default themes, `dir`, `themesLocalDir`; hidden themes sort last [code: TH:727-753,855-869 @7.x].
B11. The theme dropdown appends `mautic_code_mode` ("Code Mode") except for Forms; Email uses feature `email`, Landing Page `page`, Form `form`, the configuration form `all` [code: app/bundles/CoreBundle/Form/Type/ThemeListType.php:25-32 @7.x] [code: app/bundles/EmailBundle/Form/Type/EmailType.php:241-252 @7.x] [code: app/bundles/PageBundle/Form/Type/PageType.php:98-110 @7.x] [code: app/bundles/FormBundle/Form/Type/FormType.php:92-100 @7.x].
B12. New Emails and Landing Pages default to `blank`; when an existing entity's theme is neither `mautic_code_mode` nor installed for the feature, the form preselects `theme_email_default` [code: TH:788-795 @7.x] [code: app/bundles/EmailBundle/Form/Type/EmailType.php:234-239 @7.x]. The picker shows `thumbnail_<type>.png`, else `thumbnail.png`, else a placeholder, and lists only themes whose `features` contains the type or the currently selected theme [code: app/bundles/CoreBundle/Resources/views/Helper/theme_select.html.twig:14-22 @7.x].

## 2. Twig rendering, sandbox, variables and blocks

B13. `renderThemeTemplate()` renders any template whose name contains `@themes/` in a separate Twig `Environment` sharing loader, cache, extensions and runtime loader, with the sandbox always on; other templates render normally [code: TH:570-621 @7.x].
B14. The sandbox denies filters `map`, `reduce`, `filter` and functions `configGetParameter`, `getEntity`, `getEntities`, `source`, `ini_get`, `is_file`, `get_class`, `method_exists`, `is_class`, `is_extension_loaded`, `is_function`; all methods and properties are allowed [code: app/bundles/CoreBundle/Twig/Sandbox/ThemeSandboxPolicy.php:27-83 @7.x]. Denied calls raise `SecurityNotAllowedFilterError` / `SecurityNotAllowedFunctionError` [devdocs: https://devdocs.mautic.org/en/7.2/themes/getting_started.html#template-sandbox-restrictions]. Tests: `ThemeHelperSandboxTest::testHarmfulTwigPayloadsAreBlockedOnPagePreview`, `testSafeThemeTemplateRendersSuccessfully`; `ThemeHelperTest::testRenderThemeTemplateResolvesRuntimeBackedFiltersInsideSandbox`.
B15. `email.html.twig` variables — GrapesJS theme load: `isNew`, `content` (`[]` on reset), `email` or `page` (key = object type), `template`, `basePath` [code: GJ/Controller/GrapesJsController.php:146-177 @7.x]; sending: `content`, `email`, `template` [code: app/bundles/EmailBundle/Helper/MailHelper.php:1262-1266 @7.x]; public preview: `inBrowser` (true), `content`, `email`, `lead` (null), `template` [code: app/bundles/EmailBundle/Controller/PublicController.php:1056-1065 @7.x]. No template receives a Contact.
B16. `page.html.twig` variables — builder: `isNew`, `formFactory`, `content`, `page`, `template`, `basePath` [code: app/bundles/PageBundle/Controller/PageController.php:878-888 @7.x]; public display/preview: `content`, `page`, `template`, `public` (true) [code: app/bundles/PageBundle/Controller/PublicController.php:266-274,368-376 @7.x].
B17. `form.html.twig` (standalone `/form/{id}`): `content` (rendered form HTML), `stylesheets`, `name`, `metaRobots`, `template` [code: app/bundles/FormBundle/Controller/PublicController.php:537-562 @7.x].
B18. `message.html.twig`: `message`, `type`, `template` plus bundle extras (for example the unsubscribe form HTML as `content`) [code: app/bundles/EmailBundle/Controller/PublicController.php:266 @7.x] [code: app/bundles/FormBundle/Controller/PublicController.php:507-512 @7.x]. Docs: must echo `message` and `content` [devdocs: https://devdocs.mautic.org/en/7.2/themes/getting_started.html#html-message-html-twig].
B19. `email-validation.html.twig` (7.x after 7.2.1, unreleased; [PR #16870]): `form`, `header`, `message`, `template` [code: app/bundles/EmailBundle/Controller/PublicController.php:168-200 @7.x].
B20. `@MauticCore/Theme/base.html.twig` defines blocks `stylesheets` and `content`, emits `{pagetitle}` / `{pagemetadescription}` tokens in `<head>` when `page` is defined, and calls `outputHeadDeclarations()`, `outputScripts('bodyOpen')`, `outputScripts('bodyClose')` [code: app/bundles/CoreBundle/Resources/views/Theme/base.html.twig:1-17 @7.x].
B21. `@MauticCore/Theme/message.html.twig` extends base and defines `message_content`, choosing layout by whether `message` contains a form or unsubscribe markup [code: app/bundles/CoreBundle/Resources/views/Theme/message.html.twig:1-4,1392-1427 @7.x]. `email-validation.html.twig` extends message and adds `validation_content`, `validation_error`, `validation_enhancements` [code: app/bundles/CoreBundle/Resources/views/Theme/email-validation.html.twig:3-31 @7.x].
B22. Page and form theme templates extend `@themes/"~template~"/html/base.html.twig` and override `content` [code: themes/blank/html/page.html.twig:1-3 @7.x]. `email.html.twig` is a standalone HTML or `<mjml>` document [code: themes/aurora/html/email.html.twig:1 @7.x] [code: themes/blank/html/email.html.twig:1 @7.x].
B23. Theme Twig helpers: `getAssetUrl`, `getOverridableUrl` (`media/<path>` if present else `assets/<path>`), `getBrandPrimaryColor`, `getTextOnBrandColor`, `getTextOnBrandHelperColor`, `getRoundedCorners(size)` (from `primary_brand_color`, `rounded_corners`), `getThemeName`, `outputHeadDeclarations`, `outputScripts` [code: app/bundles/CoreBundle/Twig/Extension/ThemesExtension.php:18-70 @7.x] [code: app/bundles/CoreBundle/Twig/Helper/AssetsHelper.php:88-100 @7.x] [code: app/bundles/CoreBundle/Twig/Extension/ThemeExtension.php:30-40 @7.x].
B24. `checkForTwigTemplate('@themes/X/html/Y.html.twig')` returns the name if loadable, else tries the default theme, else throws `BadConfigurationException` (the all-themes loop checks the wrong variable, B80) [code: TH:259-267,667-701 @7.x]. Tests: `testThemeFallbackToDefaultIfTemplateIsMissing`. Error pages may come from `error_<code>.html.twig` in the theme [code: app/bundles/CoreBundle/Twig/Helper/ThemeHelper.php:98-106 @7.x].

## 3. Theme install, download, copy, hide, delete

B25. UI upload accepts only `.zip`, moves it to `themes/<name>.zip` and calls `install()`; the theme directory is the zip basename after `InputHelper::filename` [code: app/bundles/CoreBundle/Controller/ThemeController.php:59-82 @7.x]. API: `POST /api/themes/new` multipart `file`, permission `core:themes:create` [code: app/bundles/CoreBundle/Controller/Api/ThemeApiController.php:32-69 @7.x].
B26. `install()` requires `ZipArchive`; refuses names in `$defaultThemes`; aborts on absolute paths or `..` segments; requires `config.json`, `html/message.html.twig` and `html/<feature>.html.twig` per declared feature; tolerates exactly one wrapping top-level folder only if every entry is under it; extracts only extension-less or allowed-extension entries; deletes the zip at the end [code: TH:321-476,481-555 @7.x]. Tests: `testThemeIsInstalled`, `testThemeIsInstalledFromSingleTopLevelFolder`, `testThemeInstallRejectsZipSlipEntries`, `testExceptionThrownWithMissingMessage`, `testExceptionThrownWithMissingFeature`.
B27. Any stray top-level entry next to the wrapping folder (for example `__MACOSX/`) disables prefix stripping, so required files are reported missing [code: TH:522-555 @7.x] [docs: https://docs.mautic.org/en/7.2/themes/manage_themes.html#installing-a-theme].
B28. Disallowed files are dropped silently (no error) [code: TH:369-372 @7.x]. Default allow-list: json, twig, css, js, htm, html, txt, jpg, jpeg, png, gif (`theme_import_allowed_extensions`, editable in Configuration > Theme Settings) [code: app/bundles/CoreBundle/Config/config.php:261 @7.x] [code: app/bundles/CoreBundle/Form/Type/ConfigThemeType.php:92-107 @7.x].
B29. Installing over an existing non-default theme writes into the existing directory without removing old files [code: TH:408-470 @7.x].
B30. Download `zip()` writes `var/tmp/tmp_<theme>.zip` and streams it; `?stream=1` omits `Content-Disposition` [code: TH:637-662 @7.x] [code: app/bundles/CoreBundle/Controller/ThemeController.php:169-181 @7.x]. API `GET /api/themes/{theme}` streams a zip; `GET /api/themes` lists without directories [code: app/bundles/CoreBundle/Controller/Api/ThemeApiController.php @7.x].
B31. `copy()` / `rename()` create the dir `InputHelper::filename(str_replace(' ', '-', $newName))` and rewrite `config.json` `name`; collisions throw `FileExistsException` [code: TH:150-203,228-241 @7.x].
B32. Delete: the controller refuses default themes (`mautic.core.theme.cannot.be.removed`); `ThemeHelper::delete()` on a default theme only hides it [code: app/bundles/CoreBundle/Controller/ThemeController.php:259-266 @7.x] [code: TH:205-222,816-820 @7.x]. Permission `core:themes:delete`.
B33. Visibility toggling works only on default themes; state is `|`-separated names in `themes/hidden-themes.txt`, deleted when empty; hidden themes still load, sort last and get class `hide` in the picker [code: TH:24,800-853,871-899 @7.x] [code: app/bundles/CoreBundle/Controller/ThemeController.php:344-352 @7.x]. Test: `ThemeControllerTest::testThemeVisibility`.

## 4. GrapesJS builder — loading

B34. `AssetsSubscriber` injects the hashed `builder.<hash>.js/.css` from `GJ/Assets/library/js/dist/manifest.json` only on `/s/` paths and only when the plugin is published; a missing/invalid manifest, a path outside `dist/` or a missing file logs a warning and injects nothing [code: GJ/EventSubscriber/AssetsSubscriber.php:29-99 @7.x]. Tests: `AssetsSubscriberTest` (12 cases).
B35. `builder.js` overrides `Mautic.launchBuilder`, `Mautic.initSelectTheme`, `Mautic.setThemeHtml` and rewrites `#builder_url` from `s/emails/builder` / `s/pages/builder` to `s/grapesjsbuilder/email|page` [code: GJS/builder.js:175-184,200-202 @7.x].
B36. `Mautic.launchBuilder(formName)` hides the form, shows `.builder-panel`, triggers `builder:show` on `.builder` and `show` on the editor, then loads media page 1; Mautic keyboard shortcuts are reset [code: GJS/builder.js:13-47 @7.x] [code: GJS/builder.service.js:775 @7.x].
B37. Mode: `page` → webpage preset; email with MJML → `grapesjs-mjml` + theme tokens; email without MJML → newsletter preset [code: GJS/builder.service.js:776-786,834-897,909-1023 @7.x]. All modes use `storageManager: false` and CKEditor 5 inline editing [code: GJS/builder.service.js:835,923,1039 @7.x].
B38. Canvas content comes from `textarea.builder-html` / `.builder-mjml`; HTML without both `<head>` and `<body>` content throws `No valid HTML template found` [code: GJS/preset-mautic/content.service.js:127-136 @7.x]. Page mode loads the template's `<link rel=stylesheet>` hrefs into the canvas [code: GJS/preset-mautic/content.service.js:142-160 @7.x].
B39. Theme selection on a non-new entity with content asks `mautic.core.builder.theme_change_warning`, then clears and reloads [code: app/bundles/CoreBundle/Assets/js/4.builder.js:64-131 @7.x]. GrapesJS fetches `/s/grapesjsbuilder/<type>/<id>?template=<t>&resetEditorState=1`, fills the textareas, clears `.builder-json`, sets `data-grapesjsbuilder-reset=true`, and pre-compiles MJML-only responses [code: GJS/builder.js:69-114 @7.x].
B40. `GrapesJsController::builderAction` looks first for deprecated `<type>.mjml.twig`, else renders `<type>.html.twig`; output containing `<mjml>` is returned as `templateMjml` with empty `templateHtml` [code: GJ/Controller/GrapesJsController.php:146-184,229-239 @7.x]. Permissions reuse `email:emails:create` / `page:pages:create` for `new*` ids, else view own/other [code: GJ/Controller/GrapesJsController.php:27-30,120-144 @7.x].
B41. Editor state: the JS ensures a hidden `grapesjsbuilder[editorState]` textarea and, unless reset, GETs `/s/grapesjsbuilder/<type>/<id>/editor-state`; a JSON object is loaded with `editor.loadProjectData()` [code: GJS/editorState.service.js:11-29,116-151 @7.x]. The server returns `null` for `new*` ids, else `content['grapesjsbuilder']['editorState']` from JSON or PHP-serialised content [code: GJ/Controller/GrapesJsController.php:35-102,195-227 @7.x]. Tests: `GrapesJsControllerTest` (5 cases).
B42. Local backups: on every editor update after a baseline, content is saved in `localStorage['gjs-storage']` under `gjs-<mode>-<theme>-<entityId|new>`, max 10; next launch offers Restore/Dismiss if different; successful submit removes it [code: GJS/storage.service.js:4-22,138-241 @7.x].
B43. Third-party GrapesJS plugins: `window.MauticGrapesJsPlugins.push({name, plugin})`, loaded per context `page`, `email-mjml`, `email-html` [code: GJS/builder.service.js:753-771,869,974,1060 @7.x] [devdocs: https://devdocs.mautic.org/en/7.2/themes/grapesjs.html#creating-a-plugin-for-grapesjs].

## 5. GrapesJS builder — saving and persistence

B44. Apply: DC components → tokens; MJML mode compiles `editor.getHtml({cleanId:true})` with `mjml2html(…,{beautify:true})`; HTML mode serialises the canvas; writes the textareas, restores DC components, fills empty subject/name/title with `"Email <date>"` / `"Page <date>"`, POSTs with `inBuilder=1` [code: GJS/preset-mautic/buttons/buttonApply.command.js:18-59,148-173 @7.x].
B45. MJML errors abort the save with "Errors inside your template. Template will not be saved." [code: GJS/preset-mautic/mjml/mjml.service.js:18-32 @7.x] [code: GJS/preset-mautic/buttons/buttonApply.command.js:26-28 @7.x].
B46. HTML serialisation keeps the original doctype, runs `Mautic.sanitizeHtmlBeforeSave` (removes `[data-source=mautic]`, `.atwho-container`, Froala leftovers, focus attributes; normalises `url("…")`), takes only the `<body>` of `editor.getHtml()`, appends `<style>` from `getCss({avoidProtected:true})`, copies the original head if missing, and drops `<html lang>` [code: GJS/preset-mautic/content.service.js:38-106 @7.x] [code: app/bundles/CoreBundle/Assets/js/4.builder.js:64-95 @7.x]. The body-only step fixed head duplication (issue mautic/mautic#14409) [code: app/bundles/CoreBundle/Assets/js/4.builder.js:64-95 @7.x].
B47. Close does the same serialisation plus `<link>` tags for `editor_fonts` entries with a `url`; the editor is hidden, not destroyed [code: GJS/preset-mautic/buttons/buttonClose.command.js:6-89 @7.x].
B48. `inBuilder=1` makes the response include `inBuilder: true`; the JS updates URL/title, form action and the optimistic-lock `version`; validation errors appear in a GrapesJS modal [code: app/bundles/CoreBundle/Controller/CommonController.php:240-241 @7.x] [code: GJS/preset-mautic/buttons/buttonApply.command.js:69-129 @7.x].
B49. `customHtml` is sanitised on submit via `InputHelper::html()`: doctype, CDATA, IE conditionals, Outlook `<o:>/<w:>/<v:>` tags, `<script>` and comments are protected; tags `applet, bgsound, base, basefont, embed, frame, frameset, ilayer, layer, object` and attributes `codebase, dynsrc, lowsrc` are stripped [code: app/bundles/CoreBundle/Helper/InputHelper.php:40-62,365-452 @7.x].
B50. On `EMAIL_POST_SAVE`, if the request has a `grapesjsbuilder` array and the plugin is published (and translation children are not being updated): find/create the sidecar row, set `customMjml`, store decoded `editorState` (invalid JSON → null) with `updatedAt` in `content['grapesjsbuilder']`, overwrite `customHtml` from the raw request (`emailform[customHtml]`, else `customHtml`) and save again via the repository [code: GJ/Model/GrapesJsBuilderModel.php:52-105,174-184 @7.x]. Tests: `GrapesJsBuilderModelEditorStateTest`.
B51. On `PAGE_POST_SAVE`, only the editor state is stored, and only when `grapesjsbuilder[editorState]` is in the request; Landing Pages have no MJML sidecar [code: GJ/Model/GrapesJsBuilderModel.php:110-118 @7.x] [code: GJ/EventSubscriber/PageSubscriber.php:21-35 @7.x].
B52. Email drafts (`email_draft_enabled`): save-as-draft moves the new MJML to `draft_custom_mjml` and restores previous `custom_mjml` / `custom_html`; apply/discard clears `draft_custom_mjml` [code: GJ/EventSubscriber/EmailSubscriber.php:44-57,88-117 @7.x].
B53. Email delete removes the sidecar row (also `ON DELETE CASCADE`); a clone shows the source email's MJML until first save [code: GJ/EventSubscriber/EmailSubscriber.php:74-86 @7.x] [code: GJ/EventSubscriber/InjectCustomContentSubscriber.php:66-75 @7.x].
B54. `GET /api/emails/{id}` includes `grapesjsbuilder.customMjml` when published and non-empty; there is no API write path for MJML [code: GJ/EventSubscriber/SerializerSubscriber.php:37-62 @7.x]. Test: `AssertCustomMjmlTest`.

## 7. Send / display pipeline and render order

B62. Sending: `minify_email_html` minifies `customHtml`; if `customHtml` is empty and `template` set, `email.html.twig` is rendered sandboxed [code: app/bundles/EmailBundle/Helper/MailHelper.php:1229-1269 @7.x].
B63. `setBody` appends `<img src="{tracking_pixel}">` before `</body>` unless disabled [code: app/bundles/EmailBundle/Helper/MailHelper.php:806-821 @7.x].
B64. `EMAIL_ON_SEND`/`EMAIL_ON_DISPLAY` listener order: `fixEmailAccessibility` (10000; adds `<head>`, `<title>`, `lang`) → dynamic content `decodeTokens` (254) → core/contact/page/asset `onEmailGenerate` (0) → `convertUrlsToTokens` (-9999) [code: app/bundles/EmailBundle/EventListener/BuilderSubscriber.php:49-60,112-148,228-269 @7.x] [code: app/bundles/EmailBundle/EventListener/TokenSubscriber.php:29-30 @7.x].
B65. All tokens are then replaced in one `searchReplaceTokens` pass, followed by optional embedded-image conversion [code: app/bundles/EmailBundle/Helper/MailHelper.php:360-385,1414-1432 @7.x].
