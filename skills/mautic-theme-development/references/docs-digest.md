## 1. Builder (user docs)
1. GrapesJS has shipped since Mautic 3 (opt-in from 3.3-RC1) and is the default since Mautic 4 [docs: https://docs.mautic.org/en/7.2/builders/email_landing_page.html#enabling-the-builder].
2. Enable/disable at Settings > Plugins > GrapesJS, then clear `var/cache` and possibly browser cache. The page says disabling reverts to the legacy Builder; in 7.x code the legacy builder is gone and the core stub only alerts [docs: https://docs.mautic.org/en/7.2/builders/email_landing_page.html#switching-back-to-the-legacy-builder] [code: app/bundles/CoreBundle/Assets/js/4.builder.js:1-3 @7.x].
3. End-user features: drag-and-drop blocks, Style Manager, device previews, Layer Manager, code view/export [docs: https://docs.mautic.org/en/7.2/builders/email_landing_page.html#available-end-user-features].
4. Asset Manager formats: PNG, JPG/JPEG, GIF, WebP, SVG, PDF; SVG not for Emails; uploads by double-clicking an image; files are stored in `media/images/` [docs: https://docs.mautic.org/en/7.2/builders/email_landing_page.html#supported-image-formats] [docs: https://docs.mautic.org/en/7.2/builders/email_landing_page.html#uploading-images].
5. Inline text editing uses CKEditor (formatting, fonts, lists, headings, links, tables, tokens); paste from Word/Google Docs keeps basic formatting [docs: https://docs.mautic.org/en/7.2/builders/email_landing_page.html#editing-text].
6. Local-storage backup with Restore the backup / Dismiss prompt [docs: https://docs.mautic.org/en/7.2/builders/email_landing_page.html#restoring-unsaved-changes].
7. Email toolbar: device sizes, undo/redo, grids, full screen, export MJML/HTML, edit code, customisation, blocks, close [docs: https://docs.mautic.org/en/7.2/builders/email_landing_page.html#email-builder-overview].
8. 7.2: Typography category (MJML Emails only) with Text, H1–H4, Subtitle; theme typography tokens override defaults; precedence Theme defaults < component typography < inline editor [docs: https://docs.mautic.org/en/7.2/builders/email_landing_page.html#typography] [docs: https://docs.mautic.org/en/7.2/builders/email_landing_page.html#typography-styling].
9. Custom fonts via `editor_fonts` (name, font, url) in `local.php` [docs: https://docs.mautic.org/en/7.2/builders/email_landing_page.html#custom-fonts].
10. Themes must declare `"builder": ["grapesjsbuilder"]` (or with `legacy`); the 3.3 string syntax causes a 500 error [docs: https://docs.mautic.org/en/7.2/builders/email_landing_page.html#templates].
11. Image linking: `href` wraps the image only when set; bare domains get `https://` unless the value has a scheme, starts with `//`, `/`, `#`, `.`, is a single word without extension, or is a `{token}` [docs: https://docs.mautic.org/en/7.2/builders/email_landing_page.html#linking-an-image].
12. Code Mode: chosen from the theme selector; HTML edited in the Advanced tab; no preview; switching to Code Mode is one-way and choosing a theme replaces content; for small edits prefer GrapesJS code view [docs: https://docs.mautic.org/en/7.2/themes/code_mode.html#limitations].

## 2. Themes (user docs)
13. Themes control Landing Pages, Emails, Forms and message screens; Theme Manager is at Settings (cog) > Themes with Title, Author, Feature columns [docs: https://docs.mautic.org/en/7.2/themes/manage_themes.html#manage-themes].
14. 7.2 tags: newsletter, promotion, transactional, registration, contact, thank_you, download, coming_soon, adaptative (follows brand configuration) [docs: https://docs.mautic.org/en/7.2/themes/manage_themes.html#theme-tags].
15. Install: Choose file > Install; `config.json` at zip root or inside one top-level folder; stray root items such as `__MACOSX` break detection [docs: https://docs.mautic.org/en/7.2/themes/manage_themes.html#installing-a-theme].
16. Installing an existing theme overwrites it; pre-installed themes cannot be overwritten or deleted but can be hidden (greyed, moved to bottom, hidden in builders) [docs: https://docs.mautic.org/en/7.2/themes/manage_themes.html#hiding-a-theme].
17. Row dropdown: Delete (user themes only), Preview, Download [docs: https://docs.mautic.org/en/7.2/themes/manage_themes.html#deleting-a-theme].
18. Default theme in Configuration > Theme Settings preselects the theme for new Emails/Landing Pages; changing a Landing Page theme after building may hide content [docs: https://docs.mautic.org/en/7.2/themes/manage_themes.html#assigning-a-default-theme].
19. MJML theme package recipe: `assets/`, `html/email.html.twig` + `email.mjml.twig` + `base.html.twig` + `message.html.twig`, `config.json`, `thumbnail.png` (400x600); images via `getAssetUrl('Themes/'~Theme~'/assets/...', null, null, true)`; zip without enclosing folder [docs: https://docs.mautic.org/en/7.2/builders/creating_themes.html#steps-to-save-the-theme-package]. Code note: `email.mjml.twig` is deprecated and bundled themes use `'themes/'~template` [code: plugins/GrapesJsBuilderBundle/Controller/GrapesJsController.php:157-161 @7.x] [code: themes/neopolitan/html/page.html.twig:28 @7.x].
20. Tested MJML head components: mj-attributes, mj-breakpoint, mj-font, mj-html-attributes, mj-style, mj-title, mj-preview; body: mj-button, mj-column, mj-divider, mj-image, mj-navbar, mj-section, mj-spacer, mj-text [docs: https://docs.mautic.org/en/7.2/builders/creating_themes.html#head-components].

## 3. Themes (developer docs)
21. Directory structure: `html/{email,form,message,page}.html.twig`, `config.json`, `thumbnail.png`, optional `thumbnail_<feature>.png` [devdocs: https://devdocs.mautic.org/en/7.2/themes/getting_started.html#directory-structure].
22. `config.json`: name, author, authorUrl, features (each requires `html/<feature>.html.twig`), builder (page/email only; absent = legacy), tags (7.2) [devdocs: https://devdocs.mautic.org/en/7.2/themes/getting_started.html#configuration-file].
23. `message.html.twig` serves unsubscribe/resubscribe and must output `message` and `content`; every theme should include it [devdocs: https://devdocs.mautic.org/en/7.2/themes/getting_started.html#html-message-html-twig].
24. `page.html.twig` uses `{pagetitle}`, `{pagemetadescription}`, `outputHeadDeclarations()`, `outputScripts('bodyOpen'|'bodyClose')`, `{% block content %}`; `form.html.twig` serves `/form/ID`, Landing Page embeds and iframes and outputs `message`, `header`, `content` [devdocs: https://devdocs.mautic.org/en/7.2/themes/getting_started.html#twig-files].
25. Uploaded theme templates run in a Twig sandbox; restricted calls throw `SecurityNotAllowedFilterError` / `SecurityNotAllowedFunctionError` [devdocs: https://devdocs.mautic.org/en/7.2/themes/getting_started.html#template-sandbox-restrictions].
26. Thumbnails 575x600px [devdocs: https://devdocs.mautic.org/en/7.2/themes/getting_started.html#thumbnails].
27. Packagist: `composer.json` type `mautic-theme`, `extra.install-directory-name`, require `mautic/core ^5.0` (bundled blank theme now requires `mautic/core-lib ^7.0`) [devdocs: https://devdocs.mautic.org/en/7.2/themes/getting_started.html#preparing-your-theme-for-packagist] [code: themes/blank/composer.json @7.x].
28. From Mautic 7: MJML theme tokens via `<mj-class>` in `<mj-attributes>`; self-closing `<mj-class/>` breaks parsing [devdocs: https://devdocs.mautic.org/en/7.2/themes/grapesjs.html#mjml-theme-tokens].
29. From 5.1: `window.MauticGrapesJsPlugins.push({name, plugin, context: [page|email-mjml|email-html], pluginOptions})`; empty context = always; script injected via an AssetSubscriber `addScript` loading before `builder.js` [devdocs: https://devdocs.mautic.org/en/7.2/themes/grapesjs.html#grapesjs-builder-plugins].
30. From 7.2: compiled builder assets are not committed; built with Node 24 and Parcel (hashed names, `manifest.json`) on composer install/update (non-fatal), on first DDEV provision, or via `composer gjs-build` / `ddev gjs-build`; missing assets log a warning and skip the builder [devdocs: https://devdocs.mautic.org/en/7.2/themes/grapesjs.html#building-the-builder-assets].
31. `themes/system/<Bundle>/Resources/views/...` overrides any core view; review after upgrades [devdocs: https://devdocs.mautic.org/en/7.2/themes/system.html].
32. Form theming: `html/MauticFormBundle/Builder/_style.html.twig`, `form.html.twig`, `Field/` overrides; change `@MauticForm` includes to `@themes/MyTheme/...`; themes with PHP files cannot be installed through the Theme Manager [devdocs: https://devdocs.mautic.org/en/7.2/themes/forms.html].
33. Legacy builder: `data-slot="image|button|text|separator"` (Froala), `data-slot-container="1"`, `data-section="1"`, `data-section-wrapper="1"`; "planned for removal" (already removed in 6.0 code) [devdocs: https://devdocs.mautic.org/en/7.2/themes/legacy.html] [code: UPGRADE-6.0.md:4-15 @7.x].
34. (8.0 docs) optional `html/email-validation.html.twig`, not a feature; extends `@MauticCore/Theme/email-validation.html.twig`; blocks `message_content`, `validation_content`, `validation_error`, `validation_enhancements` (+ `content`); resolution Email theme → default theme → all installed themes; blank ships an example [devdocs: https://devdocs.mautic.org/en/8.0/themes/getting_started.html#html-email-validation-html-twig]. Code: on the 7.x branch, not yet released (after 7.2.1; [PR #16870]), and the "all installed themes" step never succeeds [code: app/bundles/CoreBundle/Helper/ThemeHelper.php:695 @7.x].

## 4. Admin UI design conventions (for theme and plugin UI authors)
35. Core design templates: accordion `@MauticCore/Helper/accordion.html.twig` (items `id`, `title`, `padding_inline` default true, `content`); protip `@MauticCore/Helper/protip.html.twig` (`tip`); table header keys `text`, `tooltip`, `sessionVar`, `orderBy`, `class`, `filterBy`, `target` (default `.page-list`); tiles `.tile`, `.tile-clickable`, `.tile-selectable`, `.tile-icon` [devdocs: https://devdocs.mautic.org/en/7.2/design_templates/accordion.html].
36. Prefer inactive states to hiding; disabled tabs use `.nav-tabs.nav-tabs-contained > li.disabled` toggled by JS [devdocs: https://devdocs.mautic.org/en/7.2/design/availability.html#working-with-tabs].
37. `securityIsGranted('bundle:level:permission')` in Twig hides UI by permission; backend checks are still required [devdocs: https://devdocs.mautic.org/en/7.2/design/displaying_elements_based_on_user_permissions.html].
38. Empty states: `@MauticCore/Helper/no-information.html.twig` with required `tip` and optional `link`; use specific, translated messages [devdocs: https://devdocs.mautic.org/en/7.2/design/feedback.html#no-results-template].
39. Flash messages: PHP `addFlashMessage($key, $params, $type)` with strings in `flashes.ini`; JS `Mautic.addFlashMessage` / `addInfoFlashMessage` / `addErrorFlashMessage` then `Mautic.setFlashes()` [devdocs: https://devdocs.mautic.org/en/7.2/design/flash_messages.html].
40. Notifications: inline, toast (with close button; interactive toasts must not auto-dismiss), actionable; alert classes `.alert-success|info|warning|danger` [devdocs: https://devdocs.mautic.org/en/7.2/design/notifications.html].
41. Quick filters via `quickFilters` passed to `@MauticCore/Helper/list_toolbar.html.twig`, handled by `Mautic.listQuickFilter` [devdocs: https://devdocs.mautic.org/en/7.2/design/quick_filters.html].
42. `configGetParameter('name'[, default])` reads settings in admin Twig; it is denied inside the theme sandbox [devdocs: https://devdocs.mautic.org/en/7.2/design/retrieving_system_information.html] [code: app/bundles/CoreBundle/Twig/Sandbox/ThemeSandboxPolicy.php:27-51 @7.x].
43. Utility CSS: flex (`d-`, `fd-`, `jc-`, `ai-`, …), gap (`gap-20/lg` … `gap-0`), spacing (`pa-`, `mt-`, … sizes 0–20 px, variable `--spacing-03`..`--spacing-13`, named xs–xl), all `!important`, mobile-first `-sm/-md/-lg` [devdocs: https://devdocs.mautic.org/en/7.2/design/utilities.html].

## 5. Procedures
- Create a theme: copy `themes/blank`, edit `config.json`, keep `html/message.html.twig`, zip the contents (or one wrapping folder), upload in Settings > Themes [devdocs: https://devdocs.mautic.org/en/7.2/themes/getting_started.html] [docs: https://docs.mautic.org/en/7.2/themes/manage_themes.html#installing-a-theme].
- Override a core view: copy it into `themes/system/<Bundle>/Resources/views/...`, clear cache [devdocs: https://devdocs.mautic.org/en/7.2/themes/system.html].
- Customise form styling: add `html/MauticFormBundle/Builder/_style.html.twig` and `Field/` overrides; upload manually [devdocs: https://devdocs.mautic.org/en/7.2/themes/forms.html].
- Create a GrapesJS plugin: a plugin bundle whose asset subscriber adds a script registering on `window.MauticGrapesJsPlugins` [devdocs: https://devdocs.mautic.org/en/7.2/themes/grapesjs.html#creating-a-plugin-for-grapesjs].
- Build builder assets: `composer gjs-build` or `ddev gjs-build` [devdocs: https://devdocs.mautic.org/en/7.2/themes/grapesjs.html#building-the-builder-assets].

## 6. Terminology
